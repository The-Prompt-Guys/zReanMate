# ReanMate UI Icon Pack

Reusable SVG icons for the ReanMate study-kit flows.

## Palette
- Primary blue: #1677E8
- Accent yellow: #FFD42F
- Success green: #18B96A
- White: #FFFFFF

## Included
- Navigation: arrow-left, home, classes, practice, profile, bell, plus
- Material input: camera, gallery, pdf, youtube, topic, folder
- Study modes: study-guide, quiz, flashcards, mock-exam
- Utility: book, check
- Brand references: brand-logo-open-book.png and brand-wordmark-colored-mate.png

SVG files are scalable and ready for web or mobile use.
